## About the project

This is my personal portfolio website for COS 106. It has five pages that introduce me, my skills and my projects, and it includes two working tools:

- an **Academic Planner** for keeping track of assignments, readings and revision, saved in the browser;
- a **Grade Calculator** that turns a score into a letter grade and grade point.

I built it with **plain HTML5, one external CSS file and vanilla JavaScript**. There is no framework, library or build step.


## Running it locally

Double-click `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

and open <http://localhost:8000>.
